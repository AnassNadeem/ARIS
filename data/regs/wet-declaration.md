# Wet-weather declaration

If a race is declared wet, the obligation to use two different dry-weather tyre specifications does not apply (Art. 30.5). The appointed tyre supplier provides one specification of intermediate tyre and one specification of wet-weather tyre (Art. 30.1). Intermediate and wet tyres are available when the Race Director so indicates. ARIS’s wet classifier is rule-based (DRY / DAMP / CROSSOVER / WET / DRYING) because 2024–2025 FastF1 has only five races with enough rain laps to label.
